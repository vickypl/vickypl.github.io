# Vikas Panchal Portfolio (Static)

A production-ready static portfolio site built with semantic HTML5, Bootstrap 5, custom CSS variables, and vanilla JavaScript.

## Stack
- HTML5
- CSS3 + CSS variables
- Bootstrap 5 (CDN)
- Vanilla JavaScript
- AOS animations + Font Awesome icons (CDN)

## Run locally
Open `index.html` directly in a browser, or serve with any static server.

## Notes
- Resume download button points to `assets/resume.pdf` (placeholder).
- Contact form is static and shows a UI confirmation only.
